## Upstream due diligence

The pack uses the standard library (documented Python 3.8+) and has a root [MIT license](https://github.com/Jakeschincariol/day-trader-skill/blob/3d0f4ef6986f4984b7c6bd46f7ff4f87744c3abd/LICENSE), with no per-skill license overrides in the tracked tree. PDF extraction optionally invokes Poppler's `pdftotext`; live brokerage relies on separate connectors and credentials. MIT covers code, not feed rights. This proposal borrows behavior and does not copy code, install the Claude plugin, retain provider data, or add a feed.

Yahoo/Stooq quotes may lag and do not give verified exact-leg options evidence; unofficial endpoints can throttle or change. Upstream entry infers closed intervals using timestamps; its calendar tables cover selected years. Do not port those as provider finality or an authoritative calendar. RSS/filing text and PDFs are untrusted; several fetches read whole response bodies, and ZIP/XML/PDF parsing adds resource and parser risk. Local JSON plan/price/risk/approval files are mutable, outside AlphaOS's server trust boundary. Do not connect them to authorization. SEC client identification is sent to the source; avoid copying local paths, identities, or credentials.

Time Machine excludes today and incomplete/half-day sessions, uses 78 five-minute bars per full session, resamples relative OHLC independently by nearby clock slots, and separately replays historical triggers. Seeded draws improve reproducibility, but 10,000 paths do not create 10,000 independent observations. Independent sampling loses path dependence and regime persistence. Stop-first within a two-touch candle is a convention; marking gap stops at -1R can understate loss. The conditional target-vs-stop verdict excludes neither outcomes. Its 20 full-session minimum does not ensure enough independent setup occurrences. It has no walk-forward validation, confidence interval for live edge, or executable option quotes, fees and slippage. Treat simulated underlying paths and observed underlying triggers as separate from verified paper options P&L.

## Three improvements, in order

1. **Confirmed opening-range entry evidence.** Add `modules/intraday_entry_confirmation.py` and its tests only. Use the existing gateway snapshot and NYSE calendar; fixed first 15 minutes on 5-minute bars. BUY/SELL label only the direction of the underlying; WAIT for missing/unknown/partial/delayed/stale data, incomplete opening range, no fresh first close outside, or return inside. Require an aware decision clock, provider-confirmed finality, contiguous bars, as-of-safe retrieval and a recent latest elapsed bar. Never return trade readiness. Keep the helper internal until live finality and permission can be established; #101 addresses a separate Public closing-auction validation failure and does not prove finality. Later indicators and retests need independently tested rules before promotion.
2. **Position-specific paper exits.** Start with long calls/puts and debit verticals using `entry_evidence`, `structure_economics`, `option_quote_quality`, `market_session_gate`, and #10/#75 findings. Require the exact position, fresh natural-side exit quotes and bounded friction to make an economic exit call. Test stop/target precedence, quote degradation, failed breaks, momentum deterioration, ATR invalidation, time/early close and missing/stale evidence. For credit verticals, model short-strike risk and assignment separately; for condors/butterflies use range, wing and net liquidation rules. Exits are observations and plans; no assumed execution.
3. **Verified replay and calibration.** Build on #81 evidence coverage and remediation for #75/#35, then existing `historical_economics` / `forward_distribution`. Predeclare time/regime cohorts, minimum independent sessions and triggered trades, expanding/rolling training windows and untouched validation windows; report setup frequencies including no-trade sessions, counts of excluded/unresolved observations and session-clustered confidence intervals. Reject replay P&L when exact legs, timestamped sides, liquidity or costs are missing. Compare underlying outcomes separately from options P&L. Emit EV only from sufficient, friction-adjusted, out-of-sample option evidence. Respect retention rights and stop when real evidence is insufficient.

Directional confirmation may later inform long calls/puts and directional debit/credit spreads; bearish SELL means bearish SPY/QQQ, never a recommendation to sell an option. Neutral condors and butterflies, broken-wing and long-volatility structures require distinct range/regime or volatility evidence. The helper gates no existing strategy or expiry: 0DTE, weeklies, monthlies and longer tenors retain existing support. Later shared response work should show regime, directional evidence, exact strategy/legs and prices, max loss, invalidation, targets and freshness separately; confidence only from validated evidence. Keep existing candidate selection, verified archive and risk outcomes authoritative. A failed required options safety/evidence check still means NO TRADE regardless of candle direction. Later wiring belongs in the shared backend plus REST/MCP/web projections and parity tests, not in a second dashboard or engine.

### Validation and release boundary

The tracked intraday archive directory has documentation only; the checked-in
research response fixtures are not a point-in-time series of confirmed SPY/QQQ
candles. The Yahoo TSLA fixtures are useful to audit the source pack, but cannot
validate this SPY/QQQ rule. Tests build synthetic gateway snapshots to verify the
decision mechanics. The helper has no production caller and does not change the
REST, MCP or website contracts. The current Public adapter sets final-bar
completion to unknown; it cannot produce a directional result through this helper.
